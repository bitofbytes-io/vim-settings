# Third-party colorscheme

`colors/monokai.vim` is a bundled conversion of the original TextMate Monokai
theme. Its existing header is preserved.

- **Original Monokai:** Wimer Hazenberg, created in 2006. Source/history:
  <https://monokai.pro/history>.
- **Converter:** Coloration v0.3.2 by Marcin Kulik (formerly `sickill`, now
  `ku1ik`): <https://github.com/ku1ik/coloration/tree/v0.3.2>.
  Coloration is MIT licensed; its current notice is copyright 2009–2012
  Marcin Kulik: <https://github.com/ku1ik/coloration/blob/master/LICENSE.txt>.

The generator's MIT license does not establish a license for its input theme
or this generated colorscheme. The repository's introduction of the theme
(commit `036361b6f622a5fc692e6a35fda9a7d8b3b64e06`) records no original download
URL or theme license. The conversion header identifies the tool, not the exact
TextMate source. No license for this exact bundled theme has been verified.
It is therefore excluded from Daniel Waters's MIT grant in `LICENSE`.

The original theme's license/provenance remains to be established before making
any claim about permission to redistribute it. Attribution is not a license.
